# Свадьба Михаила и Варвары

Свадебный сайт-компаньон к печатным пригласительным. Гости попадают по QR-коду с приглашения.

## Стек

- Next.js (App Router)
- Tailwind CSS
- TypeScript

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Деплой

```bash
npm run build
```
